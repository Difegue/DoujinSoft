save I don't have WiiLink / I want to send you a save file or .mio files!
First off, please make sure the files you want to send aren't already in the archive! It makes for extra busywork otherwise.
Past that, all you need is your game's save file: upload it as-is and we'll pick out the games, comics and records inside. Here are some quick ways to dump it:
  • (3)DS + GodMode9i
    If you have a flash cart or a modded DSi or 3DS, and you're playing the game using a cartridge, you can use GodMode9i to dump the savefile.
  • Wii + Save File
    You can dump the WarioWare: DIY Showcase savefile (data.bin) by copying it to a SD Card using the Wii System Menu, or to a USB drive using SaveGame Manager GX.
  • developer_boardmelonDS
    If you use melonDS, a DS emulator, the savefile for the game will be in the same folder as the ROM.
  • developer_boardDeSmuME
    If you use DeSmuME, you can go to File > Export ROM Save File... to dump the savefile. Save it as a Raw Save File.
